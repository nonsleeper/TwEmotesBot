# Twitch Emotes Bot

Бот для OBS: показывает на стриме эмоуты из чата (Twitch, 7TV, BTTV, FFZ), приветствует зрителей
с эмоутом и звуком и выводит текущую игру со временем, проведённым в ней.

## Установка

1. Скачайте архив `EmotesBot-v….zip` со страницы [Releases](../../releases/latest) и распакуйте в любую папку.
2. Запустите `EmotesBotTray.exe` — иконка появится в трее. Node.js ставить не нужно, он уже внутри.
3. Двойной клик по иконке откроет панель управления. Впишите канал, Client ID и Client Secret
   (получить: [dev.twitch.tv/console/apps](https://dev.twitch.tv/console/apps) → Create App → Redirect URL `http://localhost`).
4. В OBS добавьте источники «Браузер» (ссылки можно скопировать из меню иконки или из панели):

| Оверлей | Адрес | Размер |
|---|---|---|
| Эмоуты | `http://127.0.0.1:3000/emotes.html` | 900 × 600 |
| Приветствия | `http://127.0.0.1:3000/greeting.html` | 350 × 400 |
| Текущая игра | `http://127.0.0.1:3000/game.html` | 1920 × 1080 |

Пак спецзвуков (`special-sounds-packed.json`) входит в архив. Обычные звуки для приветствий в комплект не входят —
положите свои (mp3, ogg, wav) в `app\sounds`
(в панели: «Приветствия» → «Звуки» → «Открыть в проводнике», потом «Обновить»).

Требования: Windows 10/11 64-бит, интернет.

## Обновление

Когда выходит новая версия, в панели появляется кнопка **«Доступна новая версия»**. «Обновить сейчас» скачает её
с GitHub и перезапустит бота. Настройки, звуки, кэш эмоутов, приветствия и время игр сохраняются.

Переход со старой версии (где был `start.bat`): распакуйте новую версию поверх старой или рядом и запустите
`EmotesBotTray.exe` — он сам предложит перенести данные.

## Разработка

- `npm install`, затем `npm start` — панель на http://localhost:3001, бот запускается из неё.
- `tray\build.bat` — собрать `EmotesBotTray.exe` (компилятор C# есть в Windows).
- `tray\make-release.ps1` — собрать готовую папку `release\`.
- Выпуск версии: поднять `version` в `package.json`, описать изменения в `CHANGELOG.md`, закоммитить и запустить
  `powershell -ExecutionPolicy Bypass -File tray\publish-release.ps1` (нужен [GitHub CLI](https://cli.github.com/), `gh auth login`).

Подробности об устройстве — в [CLAUDE.md](CLAUDE.md).
